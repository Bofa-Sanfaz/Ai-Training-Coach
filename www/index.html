Connections
Automatic via Huawei Health → Strava: link Strava in Huawei Health (Me → Third-party services), join the challenge, then tap Sign in with Strava below with the fields empty — no Strava app needed. Only if you have your own Strava API app:
  1. Huawei Health app → Me → Data sharing and authorization (or Third-party services) → Strava → sign in / create a free Strava account → allow.
  2. Open strava.com/settings/api (signed in to that Strava account) and create an app: name Training Partner, category Training, website , Authorization Callback Domain: . Upload any picture as icon if asked.
  3. Copy its Client ID and Client Secret below and tap Sign in with Strava → Authorize.

Samsung Health
Watch workouts (treadmill, gym bike, elliptical, strength…), sleep, heart rate, weight, steps and VO2max, read through Android Health Connect. In Samsung Health: Settings → Health Connect → allow sharing.
Swims, treadmill & gym — automatic
Reads pool swims (with heart rate), treadmill runs, the gym bike, elliptical, rowing, stairs and strength sets straight from Samsung Health on every sync — more than Health Connect shares. One-time setup in Samsung Health: ⋮ → Settings → About Samsung Health → tap the version 10 times → Developer mode → turn on Developer Mode for Data Read. Then tap Connect and allow access.
Swims from an export (fallback)
Samsung Health doesn't share swims with Health Connect, so import them from Samsung Health's own export:
  1. Samsung Health → ⋮ → Settings → Download personal data → Download.
  2. Tap below and open Download › Samsung Health › (newest folder).
  3. Pick com.samsung.shealth.exercise….csv. For heart-rate detail also select the files in jsons › com.samsung.shealth.exercise (long-press to select several).
